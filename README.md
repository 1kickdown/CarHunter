# CarHunter

iOS app that helps you find the best car listings (Kolesa.kz, hasznaltauto.hu) with a home-screen widget.

## Features
- Search and track car listings
- Home-screen widget (`CarHunterWidget`)
- Shared data between app and widget (`SharedCarData.swift`)

## Tech
Swift, SwiftUI, WidgetKit, Xcode

## Run
Open `CarHunter.xcodeproj` in Xcode and run the `CarHunter` scheme.
